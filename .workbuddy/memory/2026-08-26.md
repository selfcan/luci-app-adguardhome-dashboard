## 诊断：dashboard 备份管理/清空日志按钮不显示
- 现象：用户通过 `GITHUB_PROXY=https://ghfast.top/ sh install.sh` 安装后，面板里**备份管理**小节和**清空日志**按钮都看不到。
- 根因结论：代码本身没问题。已读完整 `render()` 确认备份小节(668-677)与清空日志按钮(559-563)是**无条件渲染**；`node --check` 通过；git 证明 `origin/main`=HEAD 的 `dashboard.js` 含 `fetchBackups`（7 处匹配），**无未推送提交**。
- 真正原因：**ghfast.top 等 GitHub 镜像/CDN 缓存了旧的 `dashboard.js`**，且忽略了 install.sh 的 `?_cb=<时间戳>` 缓存击穿参数，导致装上的 JS 是更早、没有备份/清空日志功能的版本。安装日志的 `✓ dashboard.js` 只校验"非空"不校验内容，所以没拦住。
- 复现判定命令（路由器上）：`grep -c fetchBackups /www/luci-static/resources/view/adguardhome/dashboard.js` 返回 0 即确认是旧版。
- 临时修复（路由器直连绕开代理）：
  `curl -fsSL https://raw.githubusercontent.com/imonior/luci-app-adguardhome-dashboard/main/files/view/dashboard.js -o /www/luci-static/resources/view/adguardhome/dashboard.js` 然后清 `/tmp/luci-*` 缓存并重启 rpcd/uhttpd，浏览器硬刷新。

## 内容指纹（sha256）校验：install + 面板升级 + README
- 用户要求：install 和面板更新都要加「内容指纹比对或更优方案」，并同步更新配套文件（README 等）。
- 方案：新增仓库根 `checksums.sha256`（8 个发布文件的 sha256，key 为 `files/<relpath>`，格式 `<hash>  files/...`，与 `sha256sum` / `sha256sum -c` 兼容）。install 与面板升级都先下载它，对下载到的文件逐一比对 sha256；不一致（含代理缓存旧版、截断、被替换）立即中止并提示换代理。语义 `fetchBackups`/`list_backups` 作为 checksums 不可用时的兜底防线。
- 已实现：
  1. `scripts/install.sh`：download_from_github 增加下载 checksums.sha256；内容校验块改为 sha256（主）+ 语义（兜底），6 个文件逐一 verify_one；`sh -n` 通过。
  2. `files/luci/controller/adguardhome.lua` 的 `do_upgrade_dashboard()`：下载 checksums.sha256；新增 `sha256_of()` / `check_sha()`；verify_file 后逐文件 `check_sha`；`luac -p` 通过。`changes_package/adguardhome.lua` 同步（本地测试镜像）。
  3. `README.md`：完整性校验说明、面板升级流程图、新增「代理缓存与内容指纹校验」小节（含本地验证命令 + 命中旧版处理）、结构列表加 checksums.sha256、发布步骤加「必须重新生成 checksums.sha256」。
- ⚠️ 关键坑（已踩并已修）：`checksums.sha256` 必须在**所有源文件改动之后**再生成，否则校验会把正确的当前文件判为不匹配。本轮先改了 lua 再生成一次 → 测试发现 lua 校验 FAIL → 已重新生成并复测（真实文件全 OK、篡改文件 FAIL）。
- 验证：本地模拟 verify_one，真实文件全部 OK，追加 1 行篡改的 dashboard.js 被 sha 拦下（FAIL）。`sha256sum -c checksums.sha256` 全 OK。
- git 跟踪范围：README.md、files/luci/controller/adguardhome.lua、files/view/dashboard.js、scripts/install.sh、新增 checksums.sha256。`changes_package/` 被 .gitignore 屏蔽（本地测试用，不进 GitHub），其内的 adguardhome.lua/deploy_atomic.sh 改动仅用于本地路由器测试。
